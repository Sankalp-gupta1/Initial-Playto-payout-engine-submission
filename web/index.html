Idempotent payout engine

Hold funds once. Process them safely.

The original Django service models merchant balances from an append-style ledger. This hosted sandbox makes the same state transitions visible: create a payout with an idempotency key, reserve funds with HOLD, then settle with DEBIT or restore with RELEASE.
